
                                        Linear B-Spline (order 2, degree 1)
         1/2
  |- - - - - - - - - -|
 t0                   t                   t1                 t'                  t2                                      t3
  |-------------------|--------------------|------------------|-------------------|-------------------|-------------------|
  0                   1                    2                  3                   4                   5                   6
                      |- - - - - - - - - - - - - - - - - - - - - - - - - - - - - -|
                                                      3/2

B0,1(t)  = (t - t0) / (t1 - t0) + (t2 - t) / (t2 - t1)

B0,1(1)  = (1 - 0) / (2 - 0) + (4 - 1) / (4 - 2)
         = 1/2 + 3/2
         = 4/2
         = 2


B1,1(t) = (t - t1) / (t2 - t1) + (t3 - t) / (t3 - t2)

B1,1(1) ?= (1 - 2) / (4 - 2) + (6 - 1) / (6 - 4)
        = -1/2 + 5/2
        = 4/2
        = 2

        But since t1 < t, B1,1(1) = 0



                                                      Quadratic B-Spline


 t0                   t                  t1                 t'                  t2                                      t3
  |-------------------|-------------------|------------------|-------------------|-------------------|-------------------|
  0                   1                   2                  3                   4                   5                   6

t:

B0,2(t)  = (t - t0) / (t2 - t) * B0,1(t) + (t3 - t) / (t3 - t1) * B1,1(t)
B0,2(1)  = (1 - 0) / (4 - 1) * B0,1(t) + (6 - 1) / (6 - 2) * B1,1(t)
         = 1/3 * B0,1(1) + 5/4 * B1,1(1)
         = 1/3 * ((1 - 0) / (2 - 0) + (4 - 1) / (4 - 2)) + 0
         = 1/3 * 2
         = 2/3


t':

B0,1(t')  = (t' - t0) / (t1 - t0) + (t2 - t') / (t2 - t1)
B0,1(3)   = (3 - 0) / (2 - 0) + (4 - 3) / (4 - 2)
          = 3/2 + 1/2
          = 4/2
          = 2

B1,1(t')  = (t' - t1) / (t2 - t1) + (t3 - t') / (t3 - t2)
B1,1(3)   = (3 - 2) / (4 - 2) + (6 - 3) / (6 - 4)
          = 1/2 + 3/2
          = 4/2
          = 2


B0,2(t')  = (t' - t0) / (t2 - t') * B0,1(t') + (t3 - t') / (t3 - t1) * B1,1(t')

B0,2(3)   = (3 - 0) / (4 - 3) * B0,1(3) + (6 - 3) / (6 - 2) * B1,1(3)
          = 3 * 2 + 3/4 * 2
          = 6 * 6/4
          = 6 * 3/2
          = 9
